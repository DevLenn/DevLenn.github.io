Lernblatt - Rechnen mit Binärzahlen

1️⃣ Binärzahlen lesen (Binär → Dezimal)

Methode: Von links nach rechts verdoppeln
Starte beim ersten 1 von links → Gedankenzahl: 1
Gehe ein Bit nach rechts:
  • Bit = 0: Verdopple die Gedankenzahl
  • Bit = 1: Verdopple die Gedankenzahl und addiere 1
Wiederhole für jedes weitere Bit

Beispiel: 1011010 → Dezimal

1011010 → Start bei erster 1: Gedankenzahl = 1
1011010 → Nächstes Bit ist 0: 1 × 2 = 2
1011010 → Bit ist 1: 2 × 2 + 1 = 5
1011010 → Bit ist 1: 5 × 2 + 1 = 11
1011010 → Bit ist 0: 11 × 2 = 22
1011010 → Bit ist 1: 22 × 2 + 1 = 45
1011010 → Bit ist 0: 45 × 2 = 90
Ergebnis: 1011010₂ = 90₁₀

2️⃣ Binäre Addition

Regeln: 0 + 0 = 0 | 0 + 1 = 1 | 1 + 1 = 10 (Übertrag!)
Wichtig: Immer von rechts nach links rechnen, Überträge nach links weitergeben!
2 Einsen (1+1) = 10 → 0 im Ergebnis + 1 Übertrag
3 Einsen (1+1+1) = 11 → 1 im Ergebnis + 1 Übertrag
4 Einsen (1+1+1+1) = 100 → 0 im Ergebnis + 0 Übertrag eine Stelle + 1 Übertrag zwei Stellen nach links

Beispiel mit Überträgen:

           1  1  (zu addierende Bits)
           1  1
           1  1
         + 1  1
         -------
Übertrag:  1  0  0
Übertrag:  1  0  0
         -------
Ergebnis:  1  1  0  0

3️⃣ Binäre Subtraktion (Zweierkomplement)

Minuend + Zweierkomplement(Subtrahend)

Beispiel: 1011₂ − 0101₂

Schritt 1: Subtrahend aufschreiben → 0101
Schritt 2: Einerkomplement bilden (alle Bits umdrehen) 
0101 → 1010
Schritt 3: +1 addieren = Zweierkomplement 
  1010
+    1
------
  1011
Schritt 4: Mit Minuend addieren 
  1011  (Minuend)
+ 1011  (Zweierkomplement)
------
 10110
Schritt 5: Übertrag ignorieren (5. Bit streichen) 
10110 → 0110
Merksatz: Übertrag ganz links wird immer ignoriert!

4️⃣ Binäre Multiplikation (Shift & Add)

Methode: Von rechts nach links, bei jeder 1 addieren mit Verschiebung (Shift)

Beispiel: 11010₂ × 101₂ (5-Bit × 3-Bit)

        11010  (26 dezimal)
      ×   101  (5 dezimal)
      --------
        11010  (1. Bit ist 1 → kopieren)
       00000   (2. Bit ist 0 → Nullen, um 1 nach links verschieben)
      11010    (3. Bit ist 1 → kopieren, um 2 nach links verschieben)
      --------
Jetzt die Shifts addieren: Wie bei normaler Addition mit Überträgen! 
        11010
       00000
    + 11010
    ---------
Übertrag berücksichtigen:
    
      10000010  (130 dezimal)
Kontrolle: 26 × 5 = 130 ✓

5️⃣ Binäre Division

Methode: Wie schriftliche Dezimaldivision

Beispiel: 11001₂ ÷ 101₂ (5-Bit ÷ 3-Bit)

11001 : 101 = 101
-101↓↓
-----
  0010
  -000
  ----
   0101
   -101
   ----
      0  (Rest)
Divisor von links in Dividend "hineinpassen" lassen
Wenn möglich: 1 ins Ergebnis, Divisor abziehen
Wenn nicht möglich: 0 ins Ergebnis, nächstes Bit herunterziehen
Wiederholen bis alle Bits verarbeitet
Kontrolle: 25 ÷ 5 = 5 (Rest 0) ✓
